# Blogpost-zu-Socialmedia-Beitrag v1.0.0

## Why this release exists
Many creators and small teams lose time rewriting long-form content for each social platform. This release ships a production-ready workflow that turns one source input into multiple optimized posts with consistent tone and lower manual effort.

## Core Features
- Multi-platform generation for LinkedIn, X, and Instagram from one input
- Optional URL extraction pipeline for article/newsletter sources
- Batched generation mode to reduce model-call cost
- Freemium usage model with Stripe-backed upgrades
- Save/edit/share workflow with persistent history
